# 📄 Image to PDF Converter

🔗 Live Demo

https://harsh31205.github.io/image-to-pdf-converter/

## 🔹 Project Overview

This project is a simple web-based tool that allows users to convert multiple images into a single PDF file. It is designed to be easy to use and runs directly in the browser without requiring any installation.

## 🔹 Key Features

* Supports multiple image uploads (JPG/PNG)
* Converts all selected images into one PDF
* Each image is placed on a separate page
* Clean and user-friendly interface
* Works completely in the browser (client-side)

## 🔹 Technologies Used

* HTML for structure
* CSS for styling
* JavaScript for functionality
* jsPDF library for generating PDF files

## 🔹 How It Works

1. Open the `index.html` file in any web browser
2. Select one or more images using the file input
3. Click on the *"Convert to PDF"* button
4. The system processes the images and generates a PDF
5. The final PDF is automatically downloaded

## 🔹 Project Structure

```
image-to-pdf-converter/
│
├── index.html
```

## 🔹 Output

The application generates a PDF file named *output.pdf*, where each selected image appears on a separate page in the same order.
